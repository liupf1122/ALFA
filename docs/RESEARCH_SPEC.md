# 研究规范

研究对象为有表型条件及 rigid T1 的受试者。工程目标是学习共享隐式强度场
`fθ(x, z_i, c_it)`，其中 `z_i` 为个人 latent 网格，同一人多次扫描共享，
`c_it` 为该次扫描条件。模型拟合影像强度，不输出 SDF、分割或形变场。

待检验假设：给定同一个体 latent，条件通道能够表达扫描间变化；
年龄修改能在独立测试人群中优于保持 i2 原图不变的纵向基线。
这些是验证目标，不能从网络输入含 age 或训练 loss 降低直接推导。

优化目标为全体积均匀采样点的 L1 强度误差。没有 latent 正则、形变约束、
解剖监督、对抗损失或因果识别目标。中点缺失填充和年龄与其他条件的共线性是解释限制。

训练只更新训练人群 latent 和共享网络。验证/测试冻结网络，用固定预算优化新 latent。
重建指标的真值也用于 latent 拟合，因此解释为新受试者的拟合后重建能力。
纵向评估仅以 i2 拟合 latent，固定 latent 及其他条件，将 age 改为 i3 age 并对比 i3。

验证标准分层：接口/恢复一致性属于工程证据；固定范围全卷及前景指标属于重建证据；
跨人独立评估、i2-only 拟合、原始 i2 persistence 与不改条件基线属于纵向验证必要条件。
身份保持、病理保真及因果效应仍需单独设计评价，本项目未宣称已经满足。
