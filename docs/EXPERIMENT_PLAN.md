# 实验计划

当前只完成工程验证，正式研究运行尚未开始。

1. 使用固定 train/val/test 及 seed 42，确认表型条件和原始影像可用性。
2. baseline 采用 age、sex 两条件；无条件消融使用相同划分、训练预算、latent 大小和指标。
3. 启动前确定验证范围：默认前 8 位验证受试者的首个扫描属于开发预算；设 max_samples=null 可评估全部验证受试者。
4. 固定验证拟合预算（默认 100 步 × 16384 点），每次从固定随机初始化优化新 z，以全卷 MAE 选 best.pt。
5. 测试拟合预算默认 300 步 × 51200 点、lr=0.01。报告拟合后重建 MAE、MSE、固定范围 PSNR/SSIM 及前景 MAE。
6. 纵向测试按人选择恰好一组 i2/i3，i2-only 拟合 z。仅替换 age；报告 i3 误差、raw-i2 persistence 和不改条件的解码输出误差。

测试集不参与 checkpoint 选择。重建评估每次扫描独立拟合 z；纵向模式每人仅拟合一次 i2，
不得把 i3 强度用于优化。新表有 33 个缺失年龄，源表及训练重建保留这些行；纵向评估排除并记录缺失年龄的配对，不进行跨访视填充。
不同几何等异常应在正式评估前核查。
合成 smoke 不可作为 baseline 的科学对照。

运行期间记录配置、代码指纹、数据划分快照、依赖、设备、命令、选优指标和停止原因。
需要比较性能时应统一数据、训练步数、拟合预算、图像显示窗及前景定义；当前未做视觉效果比较。
