# blood_assays 字段说明

- 本文件解释该文件夹下各 CSV 源表的全部字段含义。
- 这些为**原始源表**，包含全部随访实例（`i0`=基线，`i1`/`i2`/`i3`=后续随访）及全部数组位置（`aN`）。
- 为避免重复，下表**每个 UKB 字段只列一行**，并在「实例」「数组」列汇总该表中出现的全部 `iN`/`aN` 取值范围。
- 列含义：`列名前缀`=CSV 中的列名（去掉 `_iN`/`_aN` 后缀）；`UKB字段ID`=对应字段编号；其余为中英文含义、值类型与字段链接。
- 取值的具体编码（Data-Coding）含义见各分类字段对应的 `coding.cgi` 页面。
