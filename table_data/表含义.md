# UKB_84436 table_data 表含义

## 根目录

| 文件 | 含义 |
| --- | --- |
| `UKB_age.xlsx` | imaging visit 年龄表，sheet 为 `38577QSM`，共 38577 行；核心列是 `ID`、`sex`、`age`、`date`、`center`，右侧还有年龄段/中心的汇总列。 |
| `filtered_aging_related.csv` | aging 相关精简表，13548 行、10583 个基础个体；包含茶/酒摄入、各疾病大类二分类、死亡、疾病数量。 |
| `filtered_aging_related_std.csv` | `filtered_aging_related.csv` 的标准化版本；`tea_intake`、`alcohol_intake`、`disease_count` 已标准化，疾病二分类不变。 |
| `full_phenotypes_std.csv` | 最终建模用综合表，13548 x 100；合并了认知、疾病、教育、生活方式、心理健康、BMI 和血压等变量。 |

## blood_assays 血液检测

| 文件 | 含义 |
| --- | --- |
| `blood_assays.csv` | 血常规/血液细胞指标，字段 `p30000`-`p30300`，包括白细胞、红细胞、血红蛋白、血小板、各类白细胞、网织红细胞等。 |

## cognition 认知

| 文件 | 含义 |
| --- | --- |
| `cognition_fluid_intelligence_reasoning_1.csv` | 流体智力题目作答与总分，含 `p20016` 流体智力分数、`p20128` 限时内尝试题数。 |
| `cognition_fluid_intelligence_reasoning_2.csv` | 流体智力题目浏览时长及 `FI12`/`FI13` 等附加题。 |
| `cognition_reaction_time.csv` | 反应时测试：卡片匹配、按键次数、首次按键时间、正确匹配平均时间。 |
| `cognition_pairs_matching.csv` | 成对匹配记忆：网格行列、正确/错误匹配数、完成时间。 |
| `cognition_prospective_memory.csv` | 前瞻记忆：答题时间、尝试次数、初始/最终答案、最终是否正确、结果。 |
| `cognition_numeric_memory.csv` | 数字记忆：目标数字、输入数字、输入耗时、正确位数、最大正确记忆位数。 |
| `cognition_matrix_pattern_completion.csv` | 矩阵图形补全：每题选择、作答时长、正确题数、看过题数。 |
| `cognition_symbol_digit_substitution.csv` | 内容与 `cognition_matrix_pattern_completion.csv` 完全相同；文件名像是误标或重复拷贝，使用前要确认。 |
| `cognition_paired_associate_learning.csv` | 词对联想学习：10 个词对答案及正确联想数量。 |
| `cognition_picture_vocabulary.csv` | 图片词汇：题组、选择、选择时长、词汇水平、不确定性。 |
| `cognition_trail_making.csv` | 连线测试：数字路径/字母数字路径的完成时间、错误数、点间间隔。 |
| `cognition_tower_rearranging.csv` | Tower rearranging 谜题：输入值、输入时长、尝试题数、正确题数。 |
| `cognition_broken_letter_recognition.csv` | 残缺字母识别：显示图像、目标字母、选择、动作历史、反应时间、正确识别数。 |
| `cognition_lights_pattern_memory.csv` | pilot 灯光模式记忆：行列数、完成时间、展示模式、回忆模式。 |
| `cognition_word_production.csv` | pilot 词语生成/语义流畅性：回答数组、词数、以 S 开头词数。 |

## health_outcome 健康状况

| 文件 | 含义 |
| --- | --- |

| `health_outcome_medical_condition.csv` | 自报医生诊断疾病及诊断年龄：糖尿病、癌症、骨折、高血压、心梗、卒中、哮喘、DVT/PE 等。 |
